YouTube Transcript Vault Personal Project
Chrome Extension · File System Access API · Static Site Publishing

Designed a Chrome extension that captures a YouTube video’s existing captions and files them as Markdown notes into a personal, browsable “learning vault” — no AI, no server, no API keys, no transcription cost. Captions already exist as text on the page; the extension fetches, formats, and saves them, then can optionally publish the vault as a static site to GitHub Pages.

Shipped
  • One-click capture → auto-formatted Markdown with chapters, description, and timestamped transcript
  • Zero AI/API dependency — deliberately scoped to avoid token cost and taxonomy drift
  • One-click Publish turns the vault into a live static site via GitHub’s API
  • Manifest V3 Chrome extension with unit-tested core library functions
