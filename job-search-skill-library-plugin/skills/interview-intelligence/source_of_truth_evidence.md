# Shared Foundation: Source-of-Truth Evidence

## Purpose

Keep every job-search decision and claim grounded in the candidate’s actual history.

## Inputs

Resumes, project records, performance results, certifications, interview examples, and user-confirmed details.

## Instructions

For each relevant capability or claim, record the evidence, source, context, and any verified result or metric. Classify it as exactly one of:

- **Demonstrated** — directly performed and supported by evidence.
- **Transferable** — adjacent experience supports the capability, but the exact task or context differs; name the bridge.
- **Formal Learning** — coursework, training, or certification without demonstrated work application.
- **No Evidence** — no support found; ask or mark unknown rather than infer.

Resolve conflicts by preferring the clearest, most recent user-confirmed source. Flag unresolved conflicts. Keep this evidence record updated when the user supplies corrections or new facts.

## Output

A traceable evidence inventory with claim, classification, source/context, verified outcome, and uncertainty or gap.

## Rules

Never invent, embellish, or upgrade evidence, ownership, seniority, tools, domain experience, dates, or metrics. Preserve distinctions between led, delivered, supported, and observed. Use transferable evidence honestly; learning is not work experience. Treat absent information as unknown, not proof of absence. This foundation governs every skill in this library.
