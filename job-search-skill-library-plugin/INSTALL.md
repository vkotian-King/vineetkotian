# Install the Job Search Skill Library

This folder is a portable Agent Plugins 1.0 package containing the orchestrator, eight job-search skills, and the shared evidence rules.

## Package it

Download this folder from the repository, then create a ZIP with the contents of this folder at the ZIP root. The ZIP root must contain `plugin.json` and `skills/` (not an additional enclosing folder).

## Install it

Use your ChatGPT or Codex client’s plugin import flow to upload the ZIP. Plugin availability and sharing depend on the client and account. To make the plugin discoverable in a public plugin directory requires a separate submission and review; this repository alone does not publish a directory listing.

The plugin provides instructions only. Bring your own job descriptions and candidate evidence. It does not include a resume, personal history, or access to a Workbench.
