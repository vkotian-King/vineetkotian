# Resume & Application Optimizer

## Purpose

Tailor a truthful, relevant application to a selected role.

## Inputs

JD profile; selected resume and verified evidence; target role/company; requested deliverable (resume, cover letter, application answers, or keywords).

## Instructions

Prioritize relevant Demonstrated evidence, then clearly framed transferable evidence. Reorder and clarify content to match role priorities; use employer terminology where accurate. Improve specificity and outcomes using verified facts. Identify missing details for confirmation rather than filling them in. Keep the candidate’s actual scope and voice.

## Output

Requested tailored material plus a short change summary and a list of claims/details requiring user confirmation.

## Rules

Apply the shared evidence foundation. Never invent or inflate tools, responsibilities, seniority, dates, outcomes, or metrics. Do not imply formal learning is job experience. Optimize for clarity and relevance, not keyword stuffing.
